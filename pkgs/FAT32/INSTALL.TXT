[Welcome]
Windows 3.1 und 3.11 starten im erweiterten Modus nicht von einer FAT32-Partition (MS-DOS 7.1 aus Windows 95 OSR2/98). Dieser Patch nach 311FAT32.COM von Rudolph R. Loew ändert zwei Befehle in WIN386.EXE. Nur nötig, wenn Windows auf einem FAT32-Laufwerk liegt.

[HexPatch]
; 311FAT32.COM (R. Loew): two instructions, all languages, Windows 3.1/3.11
Patch=%WINDIR%\SYSTEM\WIN386.EXE|66 C7 46 49 FF FF|6A FF 8F 46 49 90|2
